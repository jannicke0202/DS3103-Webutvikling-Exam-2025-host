Velkommen til SportsWorld API

I dette nettstedet får dere utviklere informasjon om hvordan bruke SportsWorld API-et.

Informasjon kan blant annet dreie seg om endepunkter, objektene og properties, datatyper, hensikten med API-et og hvem som kan bruke det.

Endepunkter

  • Hente alle spillere: https://localhost:5115/api/Athlete
  • Hente alle arenaer: https://localhost:5115/api/Venue

Et Athlete-objekt

  • Id: int, unik identifikator per spiller
  • Name: string, navnet på spilleren
  • Price: int, overgangssum for spilleren
  • Gender: string, kjønn
